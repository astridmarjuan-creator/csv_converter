Plain Text → LMS Quiz CSV Converter

Paste plain-text quiz questions, convert them, and download a CSV file ready for LMS import.

How to use this converter

  1. Fill in Course Code and Unit Number. These are required and are used to name your downloaded file (e.g. CHEM110_Unit3_Quiz CSV.csv).
  2. Paste your questions into the text box below. You can paste up to 30–40 questions at once, in any mix of the supported types.
  3. Click Convert. The app will parse and validate every question and show you a preview with a pass/fail summary.
  4. Review the results before downloading. Fix any errors shown in the preview and click Convert again — the Download button only becomes available once every question parses successfully.
Formatting tip: every question must end with a line that starts with FEEDBACK: (add your feedback text after the colon, or leave it blank). That line marks the end of one question and the start of the next, so a blank line between questions is recommended but not required.

Short answer question text

Ordering (O)

List items in the correct order, top to bottom.

Ordering question text
1. First item (correct position 1)
2. Second item (correct position 2)
3. Third item (correct position 3)
FEEDBACK:

Matching (M)

List lettered choices, then a MATCH: block pairing each item to the correct choice letter.

Matching question text
A. Choice 1 text
B. Choice 2 text
C. Choice 3 text
MATCH:
Item 1 text = B
Item 2 text = A
Item 3 text = C
FEEDBACK:
